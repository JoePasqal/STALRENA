# ПОЛНЫЙ заказ графики для ChatGPT (STALRENA) — передать целиком

Ты готовишь только графику (PNG и таблицы метаданных) для игры STALRENA: репозиторий JoePasqal/STALRENA, ветка main. Код не меняй.
Прочитай: `docs/ART_CONTRACT.md`, `assets/asset_manifest_v1.json` (каждая запись со статусом `planned` — заказ: ID, `target_path`, размер холста, pivot, масштаб, `note`), `docs/art_review/BATCH_03_REPORT.md`, `BATCH_04_REPORT.md`, `docs/ART_AUDIT.md`. Файлы называй ТОЧНО по `target_path`; сдавай приоритетами, каждый — отдельным коммитом, с обновлённым `assets/art_meta/batch_05.json` (bbox, pivot, фактический масштаб) и таблицей «нарисовано / спорно».

## Общие правила
Детализированная 2D с нарисованным объёмом, камера сверху под углом, мягкий свет сверху-слева, без длинных запечённых теней; палитра: бетонно-серый, грязно-зелёный, ржавый коричневый; герой светлее фона; опасное — красно-оранжевое; дружественное — голубое. RGBA с прозрачностью (кроме бесшовных полов). Маленькие исходники не растягивать. Текст, цифры, цены и рамки в картинки не запекать (исключение — логотип).

## ЧТО БЫЛО НЕ ТАК (учти при рисовании)
1. **Трубы «висят в воздухе».** Одиночное колено, размноженное рядом, не стоит на земле. Нужны **длинные цельные сегменты** (512×128 и длиннее), с **опорами/стойками, фланцами, креплениями к земле и контактной тенью**, часть уходит в бетонное основание или стену. Вариации: прямой участок, участок с вентилем, тройник, угол.
2. **Зелёная «коробка».** Это программная заглушка станка. Нужны настоящие спрайты станков/столбов (см. П2).
3. **Голубое поле воды.** Это заглушка. Нужна текстура воды с отражениями и **края-берега неправильной формы** (см. П2), чтобы лужа не была прямоугольником.
4. Одинаковые копии укрытий рядом выглядят картонно — делай **3–4 разных варианта** каждого типа.

## П1. Бонус-кейс, ящик с проклятием, карточки (интерфейс)
- Иконки бонусов 256×256 (поле ≥16 px): `icon.bonus.double_damage`, `sturdy_body`, `gold_vein`, `rapid_fire`, `quick_legs`, `sharp_eye`, `fast_hands`.
- Иконки дебаффов 256×256, мрачнее: `icon.debuff.slow_legs`, `weak_medkit`, `molotov`, `dull_ammo`, `frail`, `stiff_bolt`, `poor_loot`.
- Рубашки: `ui.bonus_card_back`, `ui.curse_card_back` (256×384).
- Лицевые рамки карточек без содержимого: `ui.card_face_buff`, `ui.card_face_curse` (256×384); ореол выбранной `ui.card_glow`.
- **Анимация переворота карточки:** `ui.card_flip_buff`, `ui.card_flip_curse` — 8 кадров по 256×384 в одной строке (рубашка → поворот на ребро → лицо без содержимого).
- Ящики: золотой кейс `ui.bonus_case_closed`/`open` и деревянный ящик с красной окантовкой `ui.curse_case_closed`/`open` (512×384, вид сверху под углом).
- **Анимация открытия:** `ui.bonus_case_anim`, `ui.curse_case_anim` — 8 кадров 512×384 (крышка поднимается, вспышка света: золотой / красноватый).

## П2. Укрытия и вода
`prop.concrete_block_b`, `_c`, `prop.pipe_long` (512×128), `prop.pipe_tee`, `prop.wrecked_car_b`, `_c` (на боку), `prop.machine_a`, `prop.machine_b` (станки Лесопилки), `prop.pillar`, `water.flooded` (512×512, бесшовная, без зеркальной симметрии). Плюс дополнительно: **`water.flooded_edge`** — полоса берега/кромки воды с неровной формой (прозрачная), чтобы лужа читалась как лужа.

## П3. Декор без коллизии (256×256, pivot (128,217), scale 0.5) — записи `decor.*`
Лесопилка (опилки, пень, доски, бочка, цепь, шина, погрузчик, циркулярный станок, костёр-бочка, пятно масла), Насосная (катушка кабеля, ржавая бочка, лужа масла, два щита, барьер с полосами, решётка слива, фонарный столб), Затопленный двор (коряга, сухое дерево, мешки с песком, камни, водоросли, плавающий мусор, сломанный забор, островок травы), общее (кости, пятно крови, гильзы, тряпки, сорняки, рюкзак).

## П4. Эффекты (покадровые полосы, записи `fx.*`)
`fx.fire_loop` (огонь молотова, 6 кадров 128×128, зацикленный), `fx.fire_burst` (разбитая бутылка и вспышка, 4×256), `fx.steam_puff` (пар, 6 кадров, зацикленный), `fx.explosion` (8×256), `fx.hit_spark` (искры попадания, 4 кадра), `fx.heal` (голубая аура аптечки, 6 кадров), `fx.spawn_ring` (кольцо появления врага, 4 кадра).

## П5. Трупы и анимации врагов
- Трупы: `corpse.<enemy>` для 8 врагов (256×256, pivot (128,160)), `corpse.boss.*` для 3 боссов (512×512, pivot (256,320)).
- Ходьба: `enemy.<id>.walk` — лист 1024×768, 4 кадра по строкам S, E, N (клетка 256, pivot (128,208), 8 кадров/с); для боссов `boss.<id>.walk` (2048×1536, клетка 512).
- Замах: `enemy.<id>.attack` — 3 кадра по строкам S, E, N (768×768).
- Смерть: `enemy.<id>.death` — 4 кадра в строку (1024×256); `boss.<id>.death` 2048×512.
- Сначала: drifter, runner, spitter, gunner.

## П6. Броня в движении
`armor.<light|field|heavy>.anim` — лист 1536×768: колонки walk0..walk3, hit; строки S, E, N; клетка 256, pivot (128,208). Накладка повторяет наклон тела, не закрывает руки и перчатки (в E рукав свободен).

## П7. Меню и интерфейс
`ui.logo` (1024×320, логотип STALRENA), `ui.menu_bg` (1920×1080 фон меню), `app.icon` (иконка Android 512×512 + foreground 432×432), `ui.coin` (монета 256×256).

## Как проверяем
Аудит размеров `tools/art_audit.py`, затем просмотр в игре по реальным скриншотам; статусы `integrated`/`verified` ставим мы. Существующие утверждённые файлы без причины не менять.
