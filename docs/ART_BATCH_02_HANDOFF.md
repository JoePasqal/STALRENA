## Сокеты героя, пиксели внутри клетки
S = (128,129), E = (146,125), N = (142,125). S/E выбраны по перчаткам idle; N — проекция скрытой руки. Для W используй E и зеркаль смещение относительно pivot, не координату атласа. На walk/hit возможны небольшие поправки по кадру.

Оружие первой партии не заменено. Для устранения старого смещения нужно также измерить фактический хват ВНУТРИ каждого weapon PNG, а не оставлять автоматически (64,64). Сокет тела и pivot пушки — разные точки. Дульную точку считай по двум координатам относительно реального хвата с учётом поворота/отражения/scale. Проверить, что вспышка и пули выходят из дула.

## Что сделать Claude
1. Обновить проект из main. Сохранить существующие изменения пользователя.
2. Герой: стандартная схема 6×4 уже поддержана AssetRegistry. Проверить S/E/N/W, idle, walk, hit, все четыре кадра смерти (сейчас Player сразу берёт idx=3; требуется таймер анимации смерти, если нужно показать всю последовательность).
3. Враги и броня имеют НОВУЮ схему 3×1. Текущий get_actor_frame предполагает 6×4, а get_texture(armor_id, dir) не вырезает клетку. Добавить явное чтение раскладки по метаданным или AtlasTexture/region, иначе будет целая полоса/пустые кадры. Врагов не отправлять в отсутствующую строку смерти; оставить существующий визуальный fallback.
4. Подключить сокеты из метаданных, проверить хват старых оружий, слой N за телом. На N скрытая рука: точка задана для примерки.
5. Проверить посадку накладок и перекрытие рук/перчаток (особенно E), при необходимости ограничить маску/скорректировать offsets; накладки статичные и пока не прошли игровой просмотр. При смерти броню скрывать, иначе стоящий жилет останется поверх лежащего тела.
6. Штабель по последнему запросу теперь 256×256 вместо 512×512 в manifest. Pivot (128,217); предлагаемый scale=1.0 сохраняет прежний логический размер клетки 256 единиц. Согласовать manifest/реестр; коллизии не выводить из изображения и не менять их автоматически.
7. Импорт: godot --headless --path . --import
8. Запустить проект и проверки графики, затем godot --headless --path . --script res://tools/art_report.gd > docs/ART_STATUS.md. Обновить assets/art_status.json по фактическому состоянию. Не считать наличие PNG доказательством verified.
9. Вернуть скриншоты: герой S/E/N с оружием, три вида брони, враги на новом полу, повтор пола 3×3 и препятствия; короткую запись walk/death. Зафиксировать конкретные расхождения.
