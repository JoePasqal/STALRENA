# Промпт для ChatGPT: партия 5 (передать целиком)

Ты готовишь графику для игры STALRENA (репозиторий JoePasqal/STALRENA, ветка main). Код игры пишет другой исполнитель; твоя задача — только PNG и таблицы.
Перед началом прочитай в репозитории: `docs/ART_CONTRACT.md`, `assets/asset_manifest_v1.json` (каждая запись со статусом `planned` — это заказ: ID, путь `target_path`, размер холста, pivot, масштаб, поле `note`), `docs/art_review/BATCH_04_REPORT.md`, `docs/ART_AUDIT.md`. Файлы называй ТОЧНО по `target_path`.

Общие правила (те же, что в предыдущих партиях): детализированная 2D с нарисованным объёмом, камера сверху под углом, мягкий свет сверху-слева, без длинных запечённых теней и без запечённых текстов/цифр/рамок. Палитра: бетонно-серый, грязно-зелёный, ржавый коричневый; герой светлее фона; опасное — красно-оранжевое; дружественные эффекты — голубые. PNG RGBA с прозрачностью (кроме бесшовных полов), без масштабирования мелких исходников. Коллизию изображение не определяет.

Приоритеты поставки (делай по порядку, каждый приоритет — отдельный архив/коммит):

## П1. Бонус-кейс и ящик с проклятием (интерфейс)
- 7 иконок бонусов 256×256, поле ≥16 px: `icon.bonus.double_damage` (два скрещённых патрона), `sturdy_body` (бронежилет/сердце), `gold_vein` (слиток/монеты), `rapid_fire` (лента патронов), `quick_legs` (ботинок), `sharp_eye` (прицел), `fast_hands` (магазин в руке).
- 7 иконок дебаффов 256×256, мрачнее, красно-оранжевый акцент: `icon.debuff.slow_legs` (гири/кандалы), `weak_medkit` (разбитая аптечка), `molotov` (бутылка с огнём), `dull_ammo` (тупой патрон), `frail` (треснувшее сердце), `stiff_bolt` (заклинивший затвор), `poor_loot` (пустой мешок).
- Карточки: `ui.bonus_card_back` и `ui.curse_card_back` 256×384 (рубашка: золотая/стальная и красная/тёмная), без текста, символ «?» можно нарисовать.
- Ящики 512×384, вид сверху под углом: `ui.bonus_case_closed`/`open` — металлический ящик с золотым светом; `ui.curse_case_closed`/`open` — деревянный ящик с красной окантовкой и замком, при открытии красноватый свет.

## П2. Укрытия без «картонности» (замена текущей мозаики одинаковых картинок)
Делай именно РАЗНЫЕ варианты, а не копии: `prop.concrete_block_b`, `_c`, `prop.pipe_long` (512×128 длинный сегмент без повторяющихся колен), `prop.pipe_tee`, `prop.wrecked_car_b`, `prop.wrecked_car_c` (машина на боку), `prop.machine_a`, `prop.machine_b` (станки Лесопилки — заменят программные зелёные заглушки), `prop.pillar`, и бесшовная вода `water.flooded` (512×512, без зеркальной симметрии). Размеры, pivot (128,217) и масштаб — из manifest.

## П3. Декор без коллизии (мелкие спрайты 256×256, pivot (128,217), scale 0.5) — записи `decor.*` в manifest
- Лесопилка: кучи опилок, пень, доски россыпью, бочка, цепь, шина, погрузчик, циркулярный станок, костёр-бочка (с тёплым свечением), пятно масла.
- Насосная: катушка кабеля, ржавая бочка, лужа масла, два щита, барьер с полосами, решётка слива, фонарный столб.
- Затопленный двор: коряга, сухое дерево, мешки с песком, камни, водоросли, плавающий мусор, сломанный забор, островок травы.
- Общее: кости, пятно крови, гильзы, тряпки, сорняки, брошенный рюкзак.

## П4. Трупы и анимации врагов
- `corpse.<enemy>` для всех 8 врагов (256×256, лежащий труп, pivot (128,160)) и трёх боссов (`corpse.boss.*`, 512×512, pivot (256,320)).
- Ходьба врагов: `enemy.<id>.walk` — лист 1024×768: клетки 256, 4 кадра по строкам S, E, N (W зеркалится из E), pivot (128,208), 8 кадров/с. Те же для боссов `boss.<id>.walk` (2048×1536, клетка 512).
- Замах: `enemy.<id>.attack` — 3 кадра (подготовка, пик, возврат) по строкам S, E, N, лист 768×768.
- Смерть: `enemy.<id>.death` — 4 кадра в одну строку (1024×256), направление не важно; `boss.<id>.death` 2048×512.
- Выполняй для самых частых врагов первыми: drifter, runner, spitter, gunner.

## П5. Броня в движении
`armor.<light|field|heavy>.anim` — накладка на КАЖДЫЙ кадр героя: колонки walk0, walk1, walk2, walk3, hit; строки S, E, N; лист 1536×768, клетка 256, pivot (128,208). Жилет должен повторять наклон тела и не закрывать руки/перчатки (в E рукав свободен).

## Как сдавать
- Файлы по `target_path`; в каждом архиве — обновлённый `assets/art_meta/batch_05.json` (холст, bbox, pivot, фактический масштаб) и короткая таблица «что нарисовано / что спорно».
- Не меняй существующие утверждённые файлы без причины. Не трогай код, баланс, коллизии.
- В конце каждой партии перечисли, какие записи manifest теперь закрыты, и что не успел.

Формат проверки с нашей стороны: аудит размеров (`tools/art_audit.py`), потом просмотр в игре на реальных скриншотах; статусы `integrated`/`verified` выставляем мы.
