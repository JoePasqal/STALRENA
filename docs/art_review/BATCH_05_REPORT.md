## Найденные дефекты (и что сделано)

1. **Белые квадраты вместо эффектов** — первый кадр использования текстуры, загруженной в тот же кадр, рисовался сплошным квадратом (искры, огонь, пар, взрыв). Исправлено: `AssetRegistry.warm_up(["fx.", "ui.", "icon."])` при старте + кеш ссылок. Проверено снимком до/после.
2. **Трубы «висели в воздухе»** (замечание владельца, повторное): тонкая труба рисовалась в нижней половине прямоугольника коллизии на фоне огромной тени, плюс одинокий вентиль на слотах пара. Исправлено: труба масштабируется на высоту коллизии, стоит опорами на землю, тень — тонкая, под опорами; тройник — отдельный короткий стояк; одиночные вентили заменены решёткой в полу. Проверено: `pipe_pumping_*.png`.
3. **Вода выглядела квадратной** (замечание владельца): полосы кромки накладывались прямыми прямоугольниками с разрывами в углах. Исправлено: шейдер с шумовой границей (неровный берег, тёмная кромка ила), без прямых углов; полосы `water.flooded_edge` больше не используются. Проверено: `water_flooded_*.png`. Берег визуально «гуляет» на ±20–25 px вокруг прямоугольника замедления — граница геймплея остаётся прямоугольником.
4. **Текст карточек вылезал за рамку** (длинные названия «Коктейли Молотова», «Слабая аптечка», подпись снизу). Исправлено: содержимое вписано во внутреннюю область рамки, шрифт названия подгоняется по ширине.
5. Заливка зон огня/пара была плоским оранжевым диском поверх анимации — альфа снижена (контур остаётся, граница урона читается).
6. Подложка экрана ящика была полупрозрачной (магазин просвечивал) — теперь непрозрачная.

## Старый аудитор

`tools/art_audit.py` понимает раскладки из `art_meta/*.json` (ходьба 4×3, замах 3×3, смерть 4×1, боссы, броня 6×3 = 1536×768 с пустым столбцом 5) и центрированные pivot'ы трупов. Было 44 ложных предупреждения, стало 0 (`docs/ART_AUDIT.md`). PNG не менялись. Проверки не ослаблены: размер сетки, нижняя линия фигур, касание краёв клетки, пустой столбец брони, наличие смещения трупа.

## Статусы (`assets/art_status.json`, `docs/ART_STATUS.md`)

`integrated` выставлен только тем ассетам, которые видны на сохранённых снимках; `verified` не выставлен никому (нет проверки на устройстве). Остались `prepared`: корпуса боссов/часть трупов (runner, spitter, charger, flanker, boss.*), `fx.fire_burst`, `fx.spawn_ring`, `fx.muzzle`-связанное, `water.flooded_edge` и `prop.steam_valve` (больше не используются), часть иконок бонусов/дебаффов, декор, не попавший в кадр, `app.icon*`.

## Не проверено / ограничения

- Нет запуска на телефоне; производительность измерялась только на llvmpipe.
- Звуки ящиков/карточек (мажорные для баффов, минорные для дебаффов) синтезируются кодом, прослушать я не могу; проверено лишь, что все 40 звуков генерируются без ошибок.
- Выстрел стрелка (gunner): вспышка запечена в позе атаки; отдельную вспышку для его выстрела я не добавлял. Проверено по листам кадров, не в живом бою.
- Иконка приложения/adaptive-иконка проверены только на уровне конфигурации экспорта.
