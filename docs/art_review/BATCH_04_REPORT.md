# Партия 4: интеграция и результаты проверки в игре

Снимки — из реального проекта (`tests/art_gallery.gd`, Godot 4.4.1, Xvfb/llvmpipe), файлы в `docs/art_review/batch_04/`. На телефоне не проверялось, `verified` не выставлен.

## Подключено
* **Боссы** (полосы 1536×512, S/E/N, W — зеркало E): подхватились существующей логикой 3×1 без правок кода; pivot (256,416), scale 0,5. Три босса читаются во всех четырёх ракурсах, опора на пол корректна, масштаб крупнее обычных врагов.
* **Препятствия**: `concrete_block`, `pipe`, `wrecked_car` рисуются мозаикой, покрывающей весь прямоугольник коллизии (картинки одиночные, а блоки раскладок — длинные/высокие, поэтому используется мозаика); `steam_valve` — декор у слотов опасностей Насосной, `reeds` — декор по краям воды Затопленного двора (без коллизии). Коллизии не менялись.
* **Вспышка**: `fx.muzzle` рисуется у дульной точки с привязкой (29,69), поворот и отражение по прицелу, живёт 0,07 с; для остальных случаев остаётся программная вспышка.
* **Оружие**: новые хваты/дула из `weapons.json`; огнемёт (160 px) читается заметно компактнее, рукоять у перчатки.

## Результаты
| Проверка | Результат |
|---|---|
| Боссы S/E/N/W | ок, без обрезки; метаданные `frame_bounds` у части ракурсов (узкие/плоские) не соответствуют виду — на деле силуэты нормальные |
| Вспышка у дула 7 пушек, E и W | попадает в срез ствола у всех семи; при масштабе 0,45 была слишком большой — в игре 0,3 |
| Огнемёт S/E/N | компактный, не торчит; в S/N читается как сбоку/вдоль тела |
| Препятствия в арене | не обрезаются, низ по pivot, покрывают коллизию |

## Расхождения и замечания
1. **Препятствия одиночные**: бетонные блоки/трубы/машины приходится дублировать мозаикой — вид «копипаста» (стопки одинаковых машин, ряд одинаковых труб). Нужны либо длинные сегменты (труба ≥ 256×64, бетонный блок высокий), либо несколько вариаций каждого предмета.
2. **Машина** в Затопленном дворе выглядит слишком мелкой при scale 1,0 относительно 100×100 коллизии; в игре она растягивается мозаикой до границ.
3. **Вода** по-прежнему программная (в manifest нет текстуры); камыш сидит над краем.
4. **Вспышка** асимметрична (мощнее в начале), для автомата/ЛМГ на высокой скорострельности мелькает — можно добавить 2–3 варианта кадра.
5. Накладки брони на ходьбе/hit — по-прежнему статичны (отложено).
