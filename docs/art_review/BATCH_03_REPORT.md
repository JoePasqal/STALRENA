# Партия 3: интеграция и результаты проверки в игре

Снимки и GIF — из реального проекта (`tests/art_gallery.gd`, Godot 4.4.1, Xvfb/llvmpipe), файлы в `docs/art_review/batch_03/`. Проверка на телефоне не проводилась, поэтому `verified` не выставлен ни у одного ассета.

## Подключено
* **Покадровые сокеты N**: `AssetRegistry.get_weapon_socket(dir, anim, idx)` читает `hero.weapon_socket_frames_px[dir][anim]` (точка или список по кадрам); Player передаёт текущую анимацию и индекс кадра (ходьба N — 4 точки, hit N — своя точка). Жёстких индексов в Player нет.
* Хват/дуло семи оружий — из `assets/art_meta/weapons.json` (у каждой пушки свои). Дуло = вектор хват→дуло с масштабом, поворотом и вертикальным отражением слева; на снимках пурпурный крестик стоит на срезе ствола у всех семи оружий во всех четырёх направлениях.
* Полосы 3×1 (пять новых врагов), три пола, 23+1 иконок (оружие, броня, 12 модулей, parts, аптечка) подхватываются по manifest без правок баланса и коллизий.

## Результаты
| Проверка | Результат |
|---|---|
| Броня E (light/field/heavy) | тёмный овал исчез, рукав и перчатка видны; на idle/walk/hit накладка садится приемлемо |
| Статичность жилета | остаётся: на ходьбе и в hit накладка не повторяет наклон тела (незначительно) |
| Видимая перчатка на N | перчатка видна справа от корпуса на всех кадрах ходьбы/hit; оружие следует за ней (по покадровым точкам); проверено для карабина, дробовика, огнемёта |
| Смерть героя | 4 кадра по 5 кадр/с, масштаб ровный, скачка 1,5× нет, опора в одной точке; кадр 0 — заметный наклон; броня при смерти скрыта |
| Хват оружия | пистолет, карабин, SMG, LMG, снайперка, дробовик, огнемёт: ствол в руках в S/E/W; в N лежит вдоль перчатки |
| Пять новых врагов S/E/N/W | читаются, на арене держат масштаб; Громила крупнее (170 px) как задумано |
| Полы | `floor_3x3_*`: зеркального «калейдоскопа» нет; видна лишь слабая периодичность плитки |
| Иконки | в магазине видны корректно (оружие, броня, модуль); сводный лист всех файлов — `icons_all_files.png` |

## Оставшиеся расхождения
1. **Огнемёт** нарисован крупным декоративным устройством: хват (29,55) у задней рукояти, поэтому в S/N он визуально торчит вниз/вверх сильнее остальных; для читаемости в бою нужен либо меньший масштаб спрайта, либо перерисовка под размер ~160 px.
2. **Дульная точка** у пяти новых пушек задана по центру правого края (224,64); у дробовика/снайперки реальный срез ствола может отличаться на 2–6 px, на снимках заметно только у дробовика.
3. **Броня** не повторяет позу при ходьбе/hit (статичный жилет).
4. **Оружие не качается** вместе с руками на ходьбе, привязано к точке кадра.
5. **Вода** Затопленного двора по-прежнему рисуется программными прямоугольниками поверх нового пола; текстуры воды в manifest нет.
6. Не готовы: боссы (3), `prop.concrete_block/pipe/steam_valve/wrecked_car/reeds`, `fx.muzzle`; заглушки остаются.

Статусы (`assets/art_status.json`): `integrated` — герой, пять врагов, семь оружий, 24 иконки, три пола, ящик, штабель; `prepared` — три брони, забор. Ничего `verified`.
