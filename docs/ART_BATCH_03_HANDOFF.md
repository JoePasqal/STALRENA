# Партия 3 и исправления к партии 2

Основание: docs/art_review/BATCH_02_REPORT.md, commit 45fc44a. Это художественная поставка: 35 новых игровых PNG и 5 исправленных игровых PNG. Код игры не изменён. Технические проверки и просмотр подготовленных файлов выполнены; Godot/телефон в этой поставке не запускались. Статусы изменённых ассетов выставлены prepared; прежние статусы остальных сохранены.

## Исправления
- Броня light/field/heavy: заменена только клетка E. Тёмная внутренняя часть проймы заменена настоящей прозрачностью; рукав виден через отверстие. S/N сохранены пиксель-в-пиксель. Накладки остаются статичными, поправки walk/hit в коде/по кадру ещё могут потребоваться.
- Герой: принятые S/E ряды сохранены. N перерисован с правой перчаткой за правым краем корпуса. Базовый N socket теперь (173,128); дополнительные точки по кадрам записаны в assets/art_meta/batch_02.json → hero.weapon_socket_frames_px.N. Текущий AssetRegistry читает только weapon_socket_px: чтобы оружие следовало перчатке на N, добавьте поддержку координат по кадру, без жёстких индексов в Player.
- Смерть: четыре новых кадра. Кадр 0 — заметный наклон и начало падения; кадр 1 короче из-за сгибания ног и НЕ растянут до высоты стоящего героя. Масштаб подготовлен по ориентиру размера головы (26px), а не по высоте bbox. Исходные точки опоры и коэффициенты записаны в hero.death_preparation; target root=(128,208) у всех кадров. Последние две клетки прозрачны. Сравнить переходы в игре: это ещё не engine verified.
- Лесопилка: новый рисунок без зеркальных четвертей. Пограничная коррекция сделана периодическим сглаживанием без flip/flop. Края совпадают; просмотрены 3×3 повторы. Повторяемость одной плитки неизбежна, но зеркального калейдоскопа нет.

## Новые ассеты
- enemy.charger/gunner/brute/flanker/carrier: 768×256, клетки 256×256, порядок S/E/N, pivot=(128,208). Только статичные направления. У громилы фигура 170px высотой, у человека 150px; радиусы коллизии остаются из баланса.
- weapon.smg/shotgun/lmg/marksman/flamethrower: 256×128, смотрят вправо. Силуэты дробовика и огнемёта сделаны как оригинальные фантастические игровые предметы; это не реальные модели.
- 23 иконки: 7 оружий, 3 брони, 12 модулей и parts. 256×256, прозрачность, поле не менее 16px. Иконки оружия/брони отдельно кадрированы из полноразмерных рисунков, не увеличены из боевых спрайтов.
- floor.pumping/flooded: 512×512, непрозрачные, бесшовные без зеркальной симметрии.

## Что проверить Claude после pull
1. Импортировать через godot --headless --path . --import. Текущая поддержка 3×1 и 6×4 должна подхватить PNG по прежним путям.
2. Показать пять новых врагов в S/E/N/W на арене, все семь оружий и 23 иконки в магазине.
3. Сверить хват/дуло по docs/art_review/batch_03_delivery/weapon_points.png (голубой крест — хват, пурпурный — дуло). Это обзор с разметкой, не игровая текстура.
4. Для N использовать новую точку перчатки и при необходимости координаты по кадру; проверить слой оружия за телом и попадание хвата в видимую перчатку. Для S/E координаты тела не менялись.
5. Сравнить E-броню на idle/walk/hit: исчез ли тёмный овал и свободен ли рукав. Шейдер восстановления рук можно сохранить; статичность жилета сама по себе этой поставкой не устранена.
6. Проиграть смерть 5fps: проверить общий масштаб и точку опоры четырёх кадров, отсутствие скачка при переходе в лежачую позу.
7. Проверить три пола повтором 3×3. Подготовленные просмотры в docs/art_review/batch_03_delivery/ — иллюстративные композиты, не скриншоты проекта.
8. Перегенерировать docs/ART_STATUS.md через tools/art_report.gd, затем повысить статусы только по реальным результатам. Прислать новые игровые скриншоты/GIF и список конкретных расхождений.

Боссы и оставшиеся окружение/эффекты в эту партию не входят. Баланс, размеры мира, коллизии и механики не изменять ради картинок.
