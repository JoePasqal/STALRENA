# STALRENA

Одиночная мобильная 2D-игра на выживание (Godot 4 / GDScript). Герой проходит волны на небольших аренах, между волнами тратит монеты в магазине (шесть предложений), собирает снаряжение из частей, строит сборки пассивных модулей и встречает боссов. Офлайн, без аккаунтов, PvP, рекламы и платежей.

**Версия движка: Godot 4.4.1-stable (official, `49a5bc7b6`), рендерер GL Compatibility.**
Подробная инструкция запуска, управление, экспорт и отчёт проверок — ниже (разделы дополняются по этапам).

## Запуск на ПК

```bash
godot --path . 
```

Откройте проект в редакторе Godot 4.4.1 (или запустите командой выше). Главная сцена — `res://scenes/main_menu.tscn`.

## Проверки

```bash
godot --headless --path . --import
godot --headless --path . --script res://tests/test_logic.gd
godot --headless --path . --quit-after 100000 res://tests/sim.tscn -- --waves=12 --seed=7
```
